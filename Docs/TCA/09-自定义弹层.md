# 自定义弹层

对照源码：`TCA/ContactsFeature.swift` 里的系统 sheet，和本篇的独立示例。

自定义弹层分两种，连接方式不同。

## 内容自定义，外壳仍是系统 sheet

添加联系人就是这种。`AddContactView` 是自己的表单，包在 `.sheet` 里。下滑可以关闭，所以继续用 `@Presents`、展示用的 `ifLet`，以及 `.sheet(item:)`。

判断标准：用户能不能用系统手势或系统的外部点击把界面关掉。能，就走 [系统弹窗](06-Presents与系统弹窗.md) 那一条。

## 整层都由自己画

遮罩、居中卡片、从底部滑出的自定义面板，不调用 `.sheet` 或 `.alert`。关闭按钮在你的视图里，父功能自己把可选状态设成 `nil`。

这种状态是普通可选值，不加 `@Presents`：

```swift
@ObservableState
struct State: Equatable {
    var popup: RenameFeature.State?
}

enum Action {
    case popup(RenameFeature.Action)
    case renameButtonTapped
}

var body: some ReducerOf<Self> {
    Reduce { state, action in
        switch action {
        case .renameButtonTapped:
            state.popup = RenameFeature.State(name: "")
            return .none

        case .popup(.delegate(.didSave)):
            state.popup = nil
            return .none

        case .popup:
            return .none
        }
    }
    .ifLet(\.popup, action: \.popup) {
        RenameFeature()
    }
}
```

这里的 `ifLet` 是普通重载：子状态为 `nil` 时不跑子 reducer，清掉时取消子功能还在跑的 Effect。没有 `PresentationAction`，也没有 `dismiss` 依赖。

视图自己决定画在哪里：

```swift
ZStack {
    List {
        Button("重命名") {
            store.send(.renameButtonTapped)
        }
    }

    if let popupStore = store.scope(state: \.popup, action: \.popup) {
        RenamePopup(store: popupStore)
    }
}
```

`popup` 是 `nil` 时，`scope` 得到 `nil`，遮罩不出现。点保存后，子功能发出 `delegate(.didSave)`，父功能把 `popup` 设为 `nil`，这一层消失。

多个互斥的自定义弹层，同样可以收成一个枚举，只是字段不必加 `@Presents`：

```swift
var destination: Destination.State?

enum Action {
    case destination(Destination.Action)
}

.ifLet(\.destination, action: \.destination) {
    Destination.body
}
```

视图用 `if let` 判断当前 case，把对应的自定义视图叠上去。系统的 `.sheet(item:)` 和 `.alert` 读不懂这份不带 `@Presents` 的状态。
